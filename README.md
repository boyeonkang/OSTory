# OSTory

OSTory는 영화와 드라마 감상 기록, 작품별 OST 정보, 그리고 AI 기반의 취향 분석 서비스를 통합 제공하는 Android 감상 캘린더 애플리케이션입니다.

사용자는 실제 TMDB API를 통해 영화와 드라마 정보를 실시간으로 검색하고, 작품 상세 화면에서 포스터, 제목, 장르, 줄거리, 평점 정보를 확인할 수 있습니다. 감상한 작품은 날짜, 별점, 한줄평과 함께 저장하여 캘린더 화면에 직관적인 포스터 썸네일로 기록할 수 있습니다.

또한 Google Gemini API를 직접 연동하여 작품별 대표 OST 및 삽입곡 정보를 요약해 로컬 디바이스에 저장 및 유지하고, 사용자의 감상 기록과 한줄평 등을 바탕으로 작품 취향, 음악 취향, 맞춤형 작품 추천 분석 리포트를 생성합니다.

## 주요 기능 (구현 완료)

* **온보딩 화면 제공**
  * 앱 최초 실행 시 서비스 소개 화면 노출 및 "시작하기" 진입 흐름 제어 (이후 재진입 방지 및 뒤로가기 시 앱 즉시 종료)
* **앱 런처 아이콘 적용**
  * 모바일 환경에 어울리는 고품질 OSTory 전용 런처 아이콘 적용
* **TMDB API 기반 영화/드라마 검색**
  * 검색 결과 목록 표시 (포스터, 작품 제목, 원제 또는 영어 제목, 작품 유형, 개봉/방영 연도)
  * 검색 결과가 없을 경우 "검색 결과가 없습니다." 안내 메시지 노출
* **작품 상세 정보 조회**
  * 포스터, 제목, 원제, 영화/드라마 구분, 연도, 장르 리스트, 줄거리, 평점 표시
  * 상세 화면 하단 "감상 기록 남기기" 버튼 제공
* **Gemini API 기반 OST 정보 조회 및 저장 유지**
  * 대표 OST 및 삽입곡 목록(곡명, 아티스트, 앨범 등) 표시
  * YouTube 검색 연결 지원
  * 조회 및 생성된 OST 목록은 로컬에 감상 기록과 함께 영구 저장되어 재호출 없이 지속적으로 복원 및 조회 가능
  * OST 정보가 없거나 API 호출 실패 시 직관적인 Fallback 안내 문구 표시
* **감상 기록 작성 및 수정/삭제**
  * 감상 날짜 선택, 별점 입력(1~5점), 한줄평 입력(실시간 글자 수 카운터 제공)
  * 기존 작성 완료된 기록의 별점 및 한줄평 내용을 불러와 언제든지 수정 가능
  * 휴지통 버튼을 통한 개별 기록 삭제 기능 제공
  * 필수 입력값 누락 시 저장 방지 유효성 검사 적용
* **포스터 기반 감상 캘린더**
  * 감상 기록이 저장된 날짜에 포스터 썸네일 노출
  * 월 단위 달력 이동 기능 제공
  * 날짜 선택 후 바텀 시트를 통해 해당 날짜의 감상 목록 확인 및 추가 버튼(+)으로 날짜를 연동하여 새 작품 검색 및 추가
* **다중 감상 기록 지원**
  * 같은 날짜에 여러 영화 또는 드라마 감상 기록을 중복 없이 연속적으로 등록 및 저장 가능
* **전체 감상 기록 목록 및 접기/펼치기**
  * 저장된 전체 감상 기록을 날짜별/목록별로 통합하여 볼 수 있는 리스트 제공
  * 각 날짜별 기록 카드를 접기/펼치기 터치 인터랙션으로 깔끔하게 정돈해 확인 가능
* **감상 기록 통계 및 AI 취향 분석**
  * 누적된 기록을 기반으로 한 "총 관람작 수" 및 "평균 별점" 통계 대시보드 제공
  * Gemini API 연동을 통한 선호 장르 통계, 작품 스타일/음악 취향 키워드 칩, 성향 요약 리포트, 추천 영화/드라마 리스트 제공
  * 분석된 AI 취향 결과 리포트는 로컬 저장소에 캐싱 및 저장되어 재진입 시 즉시 로드
  * Gemini API 요청 한도 초과(429 에러 등) 또는 네트워크 유실 시 크래시 없이 Fallback 안내 UI 표시
* **하단 내비게이션 및 이동 정상화**
  * 캘린더, 검색, 취향 탭 간의 꼬임 없는 네비게이션 적용
  * 특히 날짜를 지정해 검색 화면(`"search?selectedDate=..."`)에 진입한 상태에서도 하단 "캘린더" 탭 터치 시 캘린더 메인 화면으로의 복귀 동작이 완전히 안정적으로 복구되어 정상 처리됨

## API Key 설정

본 프로젝트는 TMDB API와 Gemini API를 활용합니다.
보안을 위해 실제 API Key는 Kotlin 코드, README.md, 혹은 커밋 로그에 절대 직접 작성하지 않으며, 프로젝트 루트의 `local.properties` 파일에서 안전하게 관리합니다.

1. 프로젝트 루트에 `local.properties` 파일을 생성(혹은 확인)하여 아래 내용을 추가합니다.
   ```properties
   TMDB_API_KEY=your_actual_tmdb_api_key
   GEMINI_API_KEY=your_actual_gemini_api_key
   ```
2. `local.properties` 파일은 `.gitignore`에 등록되어 GitHub 원격 저장소에 업로드되지 않습니다.
3. 다른 컴퓨터로 저장소를 가져와 실행할 경우, `local.properties` 파일을 수동으로 직접 생성한 후 API 키를 기입해야 합니다.
4. 기입된 API Key는 컴파일 시점 Gradle에 의해 `BuildConfig.TMDB_API_KEY` 및 `BuildConfig.GEMINI_API_KEY` 상수로 변환되어 앱 코드에서 안전하게 참조됩니다.

## 패키지 구조

```text
app/src/main/java/com/example/ostory/
├─ domain/
│  └─ model/              # 핵심 도메인 모델 정의

│  ├─ remote/             # 원격 API 데이터 소스
│  │  ├─ tmdb/            # TMDB API 서비스 및 클라이언트

│  ├─ calendar/           # 캘린더 홈 및 일별 기록 조회 바텀시트
│  ├─ search/             # TMDB 실시간 통합 검색 화면

│  └─ preference/         # Gemini 기반 AI 취향 분석 및 맞춤 추천 화면

   └─ theme/              # 어플리케이션 테마 및 컬러 디자인 시스템
```

## 실행 방법

1. GitHub 저장소를 복제(Clone)합니다:
   ```bash
   git clone <repository-url>
   ```
2. Android Studio를 실행하고 복제된 프로젝트 폴더를 엽니다.
3. 프로젝트 루트에 `local.properties` 파일을 생성하고 `TMDB_API_KEY`와 `GEMINI_API_KEY` 값을 추가합니다.
4. Gradle Sync를 실행하여 프로젝트를 빌드합니다.
5. Android Emulator 또는 실제 Android 기기를 연결하고 Run(실행)합니다.

## 시연 흐름 (Demonstration Flow)

앱의 주요 기능 및 화면을 순차적으로 확인하기 위한 최적의 시연 시나리오 흐름입니다.

1. 앱 최초 실행: 앱을 런처에서 기동하여 첫 소개를 전달하는 온보딩 화면이 나타나는지 확인합니다.
2. 시작하기: "시작하기" 버튼을 터치하여 메인 화면인 캘린더 화면에 정상적으로 진입합니다.
3. 날짜 선택: 달력에서 감상 기록을 작성하고자 하는 특정 날짜를 클릭하여 파란색 강조 표시를 확인합니다.
4. 작품 추가 검색: 하단에 올라온 바텀 시트의 추가 버튼(+)을 클릭해 해당 날짜가 연동된 채로 작품 검색 화면으로 이동합니다.
5. 영화/드라마 검색 및 선택: 검색창에 키워드를 입력해 실시간 검색된 목록에서 원하는 작품을 터치합니다.
6. 상세 및 OST 확인: 작품 상세 화면에서 포스터, 평점, 줄거리와 함께 Gemini가 분석한 대표 OST 목록을 확인합니다.
7. 기록 작성: 하단 버튼을 통해 감상 기록 작성 화면으로 이동해 별점과 한줄평을 기입하고 저장합니다.
8. 다중 기록 추가: 캘린더로 돌아온 뒤 포스터가 표시된 것을 확인하고, 동일 날짜를 다시 눌러 다른 작품을 추가로 검색해 저장하여 한 날짜에 여러 작품이 저장되는 것을 확인합니다.
9. 기록 확인 및 수정: 캘린더에서 작성된 기록 목록 바텀 시트를 열고, 개별 기록 카드를 펼치거나 수정 버튼을 통해 기존 정보를 변경/저장해 봅니다.
10. 통계 및 AI 취향 분석 확인: 하단 탭의 "취향"으로 이동해 누적된 관람작 수와 평균 별점 통계를 보고, AI 종합 취향 보고서 및 추천 작품 카드가 올바르게 렌더링되는지 확인합니다.

## 주의 사항

* 실제 API Key는 GitHub에 업로드하지 않습니다.
* Gemini API는 무료 요청 한도가 있으므로, 한도를 초과하면 OST 정보 조회 또는 AI 취향 분석이 일시적으로 제한될 수 있습니다.
* API 요청 한도 초과 시 앱에서는 사용자에게 안내 문구를 표시합니다.
* 영화 및 드라마 정보는 TMDB API 응답을 기반으로 표시됩니다.
* OST 및 취향 분석 결과는 Gemini API 응답을 기반으로 생성되므로 작품에 따라 결과가 다를 수 있습니다.

## 프로젝트 상태

현재 OSTory 프로젝트는 핵심 요구사항과 추가 안정화 요구사항을 포함하여 모든 주요 기능 구현을 100% 완료하였습니다. 현재는 제출을 앞두고 예외 상황(네트워크 단절 등)에 대응하는 시연 전 테스트 및 시스템 안정화 단계입니다.

### 향후 확장 기능

* SharedPreferences 로컬 데이터 저장소를 Room/SQLite 기반 데이터베이스로 마이그레이션하여 확장성 확보
* Gemini가 추천해 준 작품을 터치하면 바로 TMDB 상세 화면이나 검색 화면으로 링크하는 흐름 연동
* 오디오 재생 라이브러리를 통한 대표 OST 미리듣기 프리뷰 기능 추가
